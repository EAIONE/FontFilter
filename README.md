# 字里行间 · Windows / macOS 跨平台版

## 下载

前往 [Releases 页面](https://github.com/EAIONE/FontFilter/releases) 下载对应平台的压缩包：

| 文件 | 适用平台 |
| --- | --- |
| `FontFilter-macOS-Intel.zip` | macOS 12+（Intel 芯片） |
| `FontFilter-Windows-x64.zip` | Windows 10/11 x64 |
| `LegacyData-Import.zip` | 需要从 Windows 旧版迁移数据时使用 |

## 打开软件

- 本次 Mac 包适合 Intel iMac，macOS 12 或以上。打开“字里行间.app”，也可拖到“应用程序”。
- Windows 包适合 Windows 10/11 x64。解压整个 FontFilter 文件夹后打开 FontFilter.exe，不要只复制 exe。
- 两个平台均包含运行环境，无需另装 .NET。原 Windows 程序和原压缩包未修改。
- Mac 使用本地临时签名，未做 Apple 公证；Windows 未做发布者签名。若 Mac 阻止首次打开，可在 Finder 中右键应用选择“打开”，或到“系统设置 → 隐私与安全性”允许打开。

## 本次界面更新（0.2.4）

- 特征顺序：字体类别 → 风格气质 → 用途 → 其他维度。
- 主题设置可独立修改主题色、辅助色、强调色、滚动条色和底色；主题色控制顶栏，滚动条色不再自动加黑，底色控制整页背景。点击上方对应色块直接编辑，不再使用下拉选择。H/S/B 使用渐变色条，拖动或输入颜色时主界面实时预览并显示数值；只有“应用并保存”会写入设置，取消或关闭窗口会恢复原配色。
- 右侧字体资料可向右收起/展开，保留编辑草稿并记住收纳状态；左上角标志和中英文名称统一对齐。
- 搜索、下拉、数字输入、样文编辑和弹窗统一使用柔和主题色细边；列表标签使用偏暗主题色。
- 所有滚动条加宽、圆角、彩色显示；特征搜索留白增大，应用按钮位于右侧。
- 字体对比每种字体一整行，使用相同段落、字号和行距。
- 鼠标悬停字重选择、字号或行距时，用滚轮上下调整；字重下拉菜单展开时仍正常滚动菜单。
- 试排工作台右上角“打开字体位置”可在 Finder/资源管理器中定位本机字体文件。系统内置或无法定位的字体会明确提示，不会导出或复制字体。

## 使用

首次点击“更新字体库”，扫描本机已启用字体；支持暂停和取消。字体在两台电脑上分别扫描，软件不安装、卸载或复制字体。

搜索多个词时要求同时匹配，支持空格、逗号、加号分隔。中文字体优先，可合并家族或逐字重浏览。左侧按 Ctrl（Windows）或 Command（Mac）多选，双击或点击“加入对比”；对比最多六款，同一段文字、字号和行距。

右侧人工标签可以“应用到左侧所选结果”；家族模式会作用于该家族当前搜索命中的字重。切换当前字体时，会自动保存当前字重尚未应用的标签编辑。收藏按家族保存。标签库沿用原版 172 项分类，也显示官网及自定义标签。

默认样文按所选字体的实际字形覆盖选择简体、繁体或英文。“编辑试排文字”里可应用自定义内容或命名保存，最多 4000 字符。预览只使用所选字体，缺字以红色方框显示并列出。用于汉字字形、疏密和风格比较；不等同专业出版排版，未实现复杂文字塑形、连字和 OpenType 特性控制。

官网资料库沿用原压缩包的 2026-10-25 离线快照。扫描后会为唯一匹配的字体补充空白资料，保留已有介绍和人工标签。可以离线检索、打开官方来源或手工补充介绍。资料不能作为商用授权证明。

API 设置支持 DeepSeek、OpenAI 及 Chat Completions 兼容接口。地址和模型保存在本机，密钥仅留当前进程。点击“分析当前字体”后先核对服务和发送内容，再点“开始分析”；候选默认不勾选，勾选并确认后合并到人工标签。不会批量自动调用 API，也不上传字体文件和路径。没有提供真实密钥，本次没有验证真实付费服务调用。

## 导入 Windows 旧版数据

1. 关闭旧软件，将旧版整个 app/Data 文件夹复制到目标电脑。
2. 新版先扫描本机字体，再点击右侧“导入旧版 Data”，选择该文件夹。
3. 软件先读取包含 WAL 事务的安全数据库快照，再备份当前数据库。只在字体家族与字重唯一对应时关联，保留现有人工标签和非空介绍。
4. 未安装或有同名歧义的字体不会强行关联，记录保存在新数据目录的 ImportHistory/unresolved-*.json；旧源快照、导入前数据库及被替换设置的备份也在这里。
5. 安装并启用相应字体后可重新扫描，再次导入原 Data。不要把旧 Windows 字体路径当作 Mac 字体。

两台电脑数据各自保存，没有自动云同步。可以分别导入相同旧数据；以后若要转移新标注，也可关闭软件后复制整个数据目录并使用导入功能。

## 数据与备份

Mac：`~/Library/Application Support/FontFilter`。
Windows：`%LOCALAPPDATA%\FontFilter`。
右侧“打开数据文件夹”可直接定位。可通过 `FONTFILTER_DATA` 环境变量指定另一目录。备份时先退出软件，再复制整个目录；不要在数据库正在写入时仅复制 fonts.db。

扫描遇到不可读取字体时保留原索引，状态栏显示异常数量，详情在 scan-errors.log。取消扫描保留已扫描进度，不进行全库移除判定。启动错误会写入 startup-error.log。

## 源码与构建

共享核心在 src/FontFilter.Core，跨平台界面和系统字体服务在 src/FontFilter.Desktop；original 保留提取出的 Windows 源码供参考。开发需要 .NET 8 SDK，UI 依赖锁定 Avalonia 11.3.22 和其 Skia 渲染依赖。

```sh
dotnet run --project tests/FontFilter.Tests
dotnet run --project src/FontFilter.Desktop
# macOS 主机同时构建 Mac 与 Windows 包
bash scripts/publish.sh
```

Windows 主机可运行 `scripts/publish-windows.ps1`。开发 SDK 和下载缓存不会进入交付源码压缩包。

验证记录见 docs/verification.md；Mac 实机验证与 Windows 交叉构建验证分别说明。
