# 特征顺序与三色主题 · 2026-10-27

按用户要求，特征标签固定先显示字体类别、风格气质、用途，再保留其他维度原来的相对顺序，自定义标签仍在最后。
主题拆为主色（顶栏与品牌）、辅助色（标签与选中背景）、强调色（主要按钮与选中指示）。三者独立调整、保存，提供十六进制及 HSB 编辑。旧单色设置继续作为主色；新颜色使用默认辅助浅绿、强调暖金。取消不修改当前设置，文字自动选择可读的深浅颜色。

执行：先加入排序、独立保存及旧设置兼容回归；实现共享调色板和 UI；实际检查标签顺序及三色调整；重新发布两端、替换本次生成的 Mac 应用（正常退出保存后备份旧包），保留用户数据。

用户后续截图要求已纳入：搜索框上下留白、筛选按钮靠右、全局 24px 宽圆角彩色滚动条、字体对比单列满宽、字重/字号/行距滚轮调整、打开本地字体位置、独立浅色顶栏底色。
