# 浏览与页面试排

按用户已明确的界面修改执行，保持 Mac 与 Windows 共用实现。

- 浏览结果时隐藏常用标签和筛选控件；返回上方控件区恢复。结果行使用 3px 行内间距、7px 上下内距。
- 字体对比隐藏当前字体卡片；离开对比恢复。资料收起为右上角透明小按钮。
- 收藏提示：仅看收藏中的筛选结果；退出收藏，查看全部匹配字体。
- 点击列表、当前卡片、试排卡片的字体名称复制家族名，底部反馈。
- 页面试排使用 A5，四边距 mm，字号/字距 pt，行距倍率。依版心分页并交替订口/切口；共享当前样文，真实字体绘制，缺字不替换。
- 验证：核心回归、真实字体界面检查、页面尺寸与边距实时调整、剪贴板、对比隐藏、收起高度。完成 Mac 与 Windows 打包。

## 0.2.6 用户图示修订
- 收藏范围提醒用红字。右上打开字体位置和资料折叠顶对齐，资料折叠显示竖排标题和下方箭头。
- 标签库/常用标签采用并集，手输关键词仍保留搜索语义；并集不可绕过收藏/active范围。
- 页面模式隐藏当前卡片及通用排版工具，改为左字体候选/参数、右完整书页。Viewbox按宽高等比适配，不用滚动露出被裁书页；单页翻页。
- 默认185×260 mm，提供用户图示12种预设以及自定义尺寸，保存宽高。
- 验证预设切换、真实字体候选、缩放不越界、边距以及核心并集回归。

## 0.2.7 分段长文
用户追加要求页面放满文字且自然分段。新增独立页面样文模式，默认近4000字分段内文、两字首行缩进，按版心分页；页面编辑不修改字体试排的样文。验证长度、段落缩进、默认模式和真实页面的文字容量。

## 0.2.8 单页、缩进、候选及并集修复
页面固定1P并重复段落到版心容量加溢出行，不再提供多页导航；段落先去除原缩进，再使用固定两个em空格，绘制端全角空格只占位不绘制。候选只从State.Comparison构建，空对比即空候选。标签并集保留生成的查询字符串，延迟TextChanged通过当前字符串判断来源，不依赖同步bool守卫；实际UI等待事件后比对黑体/宋体合集。NumericUpDown本身和模板编辑器设双向居中，行内标签、ComboBox与Button统一垂直居中。验证空/有候选、候选独立选择、单页、真实延迟标签事件、数字模板属性及截图。

## 0.2.9 三栏、工作台模式入口、体例与换行
按用户明确布局：页面候选190px左列、等比书页中列、设置300px右列；页面模式隐藏字体资料与入口并回收列宽，保留用户原折叠偏好。模式切换按钮放到标题右侧，原TabControl仅负责内容与状态，其原生标题隐藏。
长篇体例提供简体、繁体、英文、中英混排。旧样文键迁移，页面编辑仍独立保存。
共享Core的BookLineBreaker根据字素、完整单词、常用开闭标点分组测量换行，输出预排好的行；GlyphPreview.PreformattedLines保证不进行二次逐字换行。保持单页、两字首缩进和足够溢出。对超过整行宽度的单词不硬拆，保留并裁切；这是本预览器对极端版心的限制。
规则参考官方 Unicode UAX #14 (https://www.unicode.org/reports/tr14/) 与中文排版需求草案 (https://www.w3.org/TR/clreq/)，是针对常见书页的实现，未声称完整Unicode标准合规。
验证Core标点、词、组合字素、体例迁移；真实页面简/繁/英模式、三列位置、资料隐藏、缩放和状态恢复；两个平台打包。
