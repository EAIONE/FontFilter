# 字里行间：Windows / macOS 跨平台迁移

## 用户决定与目标
用户提供 FontFilter.zip，要求在 iMac 上使用，并明确选择跨平台版本，Windows 也要继续使用。一套源码分别发布 macOS .app 与 Windows 可执行程序；保留原 Windows 包，不原地覆盖。

## 方案
已讨论原生 Mac 重写与共用代码的跨平台迁移，用户选择后者。实现建议采用 C# / Avalonia：复用原 C# 数据模型、标签规则、官网资料和 AI 接口逻辑，替换 Windows WPF 界面、系统字体接口和 SQLite 平台绑定。Electron 需要重写更多现有逻辑，维护两套原生界面不符合共用代码目标。具体框架是实施者建议，待用户确认本文。

## 保留的功能
沿用字里行间名称、图标、暖白墨绿三栏工作台及主题颜色设置。保留中文优先、家族合并与字重选择、关键词 AND 搜索、172 项标签及常用标签、收藏、人工标签编辑、官网资料库和手动介绍、API 设置与经用户确认的单字体分析。保留样文编辑与保存、字号行距、缺字提示及最多六款对比。扫描在后台执行，支持暂停、取消及增量复用；读取异常或取消不触发全库移除。

## 架构与平台差异
共享核心层负责模型、搜索、标签、持久化、官网资料和 AI 客户端；桌面层使用 Avalonia；字体发现、真实字重定位和字形覆盖检测通过可测试的服务封装。缺字须明确提示，预览不能用其他字体替代缺失字形而不提示。字体身份需包含足以区分字体来源与样式的信息，不能只按显示名称匹配。
SQLite 使用两平台可用的实现，保留原有表和字段的兼容性。字体文件不安装、不卸载、不复制。按平台使用合适的界面默认字体和快捷键。

## 数据与迁移
新数据默认保存在用户可写的应用数据目录，Mac 使用 ~/Library/Application Support/FontFilter，Windows 使用本地应用数据目录下 FontFilter。继续支持 FONTFILTER_DATA 覆盖。离线 official-fonts.json 作为应用资源分发。
提供显式旧 Data 导入：先备份，安全读取 SQLite（考虑 WAL，不能只复制正在写入的主库），导入设置、收藏、人工标签和介绍。Windows 路径在 Mac 无效，必须重新扫描本机字体；跨平台标签关联仅在字体家族及字重唯一对应时迁移，歧义项保留并报告，不擅自合并。不打包旧机器扫描索引作为本机有效字体。不会默认云同步或复制字体文件。密钥仅留当前进程内存。

## 交付
保留原压缩包，独立提供迁移源码、Intel macOS .app、Windows x64 包及简短中文说明。自包含发布，普通使用者无需单独安装 .NET。Apple Silicon 包不作为本次必需交付，后续可从同一源码构建。应用未取得 Apple 开发者证书，不声称已公证。

## 验证与边界
核心验证覆盖 AND 搜索、人工标签和收藏持久化、旧数据导入及歧义保护、API 密钥不落盘、扫描取消与异常保护、预览缺字与六款对比限制。当前 Intel iMac 执行真实扫描和启动检查；Windows 交叉构建及静态检查，在没有 Windows 执行环境时明确交付说明其尚待 Windows 实机验证。检查应用包资源、原生依赖与启动错误日志。
不新增字体安装、自动云同步、批量付费 AI 调用或专业排版引擎。实现中可以自行决定代码组织和控件细节，不减少上述功能；不能实现的项目明确列出，不能宣称全部完成。
