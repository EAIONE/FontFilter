# 字里行间 · FontFilter

运行：打开本项目 app 文件夹中的 FontFilter.exe。需要 Windows 10/11 和 .NET 8 Windows Desktop Runtime（本机已存在）。程序不安装、不卸载、不复制字体文件。

## 使用

首次点击“扫描 / 更新字体”；已有索引时可以直接搜索。关键词用空格、逗号或加号分隔，多个词要求同时匹配。点击快捷分类可以替换搜索词。“标签筛选”打开172项、8个维度的分类标签库，可多选后加入搜索或填入人工标签框。中文字体优先，并结合实际汉字覆盖检测；中文名称在同一类别中优先。默认按家族合并，右侧切换字重；取消合并可以逐个样式浏览。

在人工标签框输入词语，点击“应用到选中结果”将替换所选结果的人工标签。按Ctrl可多选家族；家族模式下操作的是当前搜索命中的样式。更新扫描和官网资料不会覆盖人工标签。清空标签框后应用可清除人工标签。

书名、正文、诗词样文可直接切换，也可输入自定义段落并保存为样文。最大4000字符。点击“加入对比”会自动切换到对比页，也可在左栏按Ctrl多选后点击对比页“加入左侧所选字体”；每个选中家族取当前样式或首个匹配样式。双击列表可快速加入。最多六款对比，可逐款移除、去重，使用相同段落、字号和行距；缺字显示缺字框并提示，不偷偷使用其他字体。预览以中文单字字形比较为主，不实现复杂文字塑形、连字、OpenType特性或正式出版排版校样。

“查找官方页面”在浏览器中检索选中字体。找到方正/汉仪官方详情页后，用“补充官网介绍”粘贴地址提取，或直接粘贴介绍摘要。提取结果可能包含导航或通用说明，请先删去无关文字并核对字体，再勾选确认关联。此版本不自动爬取整个字体网站。网站动态加载、访问限制或超时均可改为手动摘要；不绕过网站访问限制。

默认标签来自本地规则词典和人工标注，也可选用右上角API连接进行AI辅助标注。官方介绍里的明确用词可产生候选标签；“风骨”等主观气质不会凭空推断。搜索仍为关键词交集。AI用于当前字体的文字介绍分析，不是字形图片识别，也不会自动处理整个字库。授权需要自行核对官方许可，程序不判断是否可商用。

## 数据

数据保存在 app/Data：fonts.db 是SQLite字体索引和标签；settings.json 是样文与试排设置；scan-cache.json 是增量缓存。备份时关闭程序并复制整个Data目录。程序默认便携运行；不能写入目录时会提示错误。已移除字体从列表隐藏，保留标签以便同一来源重新安装时恢复。

字体列表只显示文字信息，使用回收式虚拟化；选中及对比时才创建真实字体预览。字体元数据首次读取仍有开销；后台扫描支持暂停和取消，取消不清除已有索引。存在读取异常时，不执行全库移除判定，以免误删索引。

## 构建与验证

在项目根目录运行：

    dotnet build tests/FontFilter.Tests -c Release --artifacts-path artifacts/check
    dotnet artifacts/check/bin/FontFilter.Tests/release/FontFilter.Tests.dll --integration
    dotnet publish src/FontFilter -c Release --artifacts-path artifacts/check -o app --no-self-contained

.NET SDK 固定为本机可用的8.0.407；SQLite调用Windows自带winsqlite3，不需要NuGet下载。第一次构建无外部包。某些受限环境缺少APPDATA、USERPROFILE或ProgramFiles(x86)会导致SDK还原失败，应在正常Windows开发终端执行。若SDK工作负载解析异常，可为构建传入 -p:MSBuildEnableWorkloadResolver=false。

## 浅色工作台与API

新版采用暖白和墨绿配色：左侧中文优先字体列表，中间试排与对比，右侧字体资料和人工标签，底部固定对比台。样文编辑在“编辑试排文字”中展开。

点击右上角“API设置”，选择DeepSeek、OpenAI或自定义兼容接口，填写Base URL、服务支持的模型名称及API密钥。模型名不预设，按服务商控制台填写。地址与模型配置会保存；密钥只存在本次进程内存中，关闭程序后需要重新填写。接口需要支持Chat Completions；不支持JSON输出模式时可取消勾选。

选中字体，点击右侧“分析当前字体”，在弹窗查看目的服务与发送内容，点击开始后才发出API请求。仅发送当前字体名称、字重和已保存的介绍（最多4000字符），不上传字体文件、路径或人工备注。API调用可能产生服务商费用。

返回的标签需属于现有172项词库，且引用依据能在输入资料中找到。候选默认不勾选；人工核对后确认，才合并保存到当前样式的人工标签，保留编辑框中尚未保存的标签。没有介绍时无法可靠判断结构、气质和用途，建议先补充官方资料。模型仍可能误解资料，不代表标签已客观验证。

已通过模拟HTTP传输、响应解析、错误处理、密钥不落盘与依据筛选测试；没有用户密钥，尚未验证真实服务商调用。
