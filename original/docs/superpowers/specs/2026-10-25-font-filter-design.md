# 字体筛选器设计

已批准：Windows 独立桌面程序，C# / WPF / SQLite，不接 AI API。

读取系统安装字体，按家族归组并展开字重，记录名称、厂商和路径。官网资料仅手动触发补充，保存摘要、来源和更新时间；不确定匹配交由用户确认。标签分为类别、笔画、结构、气质、用途，区分官网依据、规则推断和人工标注，人工修改优先。支持多关键词组合、匹配原因、批量标签编辑。

预览提供书名、正文、诗词和自定义段落，调整字号、行距，最多六款对比；缺字明确提示。后台增量扫描，虚拟化列表，按需预览和有界缓存。索引建立后查询目标200毫秒内返回，须以用户真实2000—3000款字体验证，不提前承诺实测结果。

方案比较：桌面程序可直接访问系统字体并控制渲染；本地网页需要字体访问桥接；纯离线不能补充官网介绍。用户选择桌面程序及可选官网缓存。第一版不含安装卸载、云同步、商用授权自动判定。
